Inference Pipeline Overview

Applicant features are mapped through a serialized Scikit-learn ColumnTransformer Pipeline, performing median imputation for numerical terms, categorical one-hot encoding for home ownership and loan intent, and calibrated probability estimation via an extreme gradient boosted decision forest.

Decision Optimization Logic

Rather than employing a naive 50% probability threshold, the underwriting engine utilizes a loss-matrix-optimized threshold at 73.31% to penalize false negative default classification while maximizing loan origination volume.
